## 内容大纲（两份平行翻译，均以仓库实际事实为准）

1. **标题 + slogan + 语言切换链接**
2. **这是什么** —— lh-ui 家族的 Vue 2.7 UI 层；一个 core（`@lh-ui/share` 纯函数）+ 薄 UI 层；不持有 core/样式/文案副本；peer `vue@^2.7.0`；不支持 Vue 2.6 及 IE11；指向 plus（Vue3 旗舰版）
3. **特性** —— 一个 core 多端复用 / 国风水墨设计 / CSS 变量主题（全局 + ConfigProvider + 组件 themeVars）/ i18n（zh-CN、en-US）/ tree-shaking（ESM+CJS+UMD + `.install()`）/ TypeScript 优先
4. **安装** —— 如实说明尚未发布 npm，走 `link:../lh-ui-share` 联调，给出先构建 share 再 install 的步骤
5. **快速上手** —— 全量引入、按需引入（`@lh-ui/vue2/style/button` 单组件样式）、ConfigProvider 全局配置；代码取自 `docs/guide/quickstart.md` 的真实示例
6. **主题** —— `--lh-*` 令牌唯一源在 share；暗色 `theme-dark.css` + `data-theme="dark"`；`usePresetTheme` / `useLhTheme`；覆盖优先级（组件 themeVars > componentTheme > 全局）
7. **组件清单** —— 取自 `src/index.ts` 的 `lhComponents` 注册表，按 docs 侧栏分组：基础（ConfigProvider/Button/Icon）、数据录入（Input/Select/Checkbox/CheckboxGroup/Radio/RadioGroup/Switch）、反馈与展示（Dialog/Tooltip/Tag/Form/FormItem）；另列「开发中未登记」的 10 个（Alert/Avatar/Badge/Card/Divider/Empty/Progress/Skeleton/Space/Spinner）
8. **开发命令表** —— `pnpm dev`（5174）、`docs:dev`、`test`/`test:watch`、`lint`/`lint:fix`、`typecheck`、`build`、`build:demo`、`changeset`；附一句 iframe 沙箱示例方案说明
9. **约定与规范** —— pnpm、中文注释与提交、BEM `lh-*`、changeset、share 先发版的硬约束、引导读 AGENTS.md（Vue2 红线）
10. **文档** —— 在线站 `https://lh-ui.lhgb.top/vue2/`（取自 docs config 的 DOCS_HOSTNAME 默认值）、家族总纲与 vue2 计划文档链接
